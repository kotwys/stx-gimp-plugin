## v1.0.0 (2026-10-06)

This is a major release of file-stx including a total rewrite for GIMP 3. The
program is now licensed under GNU GPL 3.

* _An experimental functionality of opening and saving PlayStation® 2 textures
  was added._
* User interface was fully refined with translations in Russian and Japanese.
* The export dialog infers settings based on the currently opened file.
